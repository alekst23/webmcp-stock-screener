# The WebMCP Challenge — Summary

Source: https://webmcp.devpost.com/ (main page + rules page), fetched 2026-08-26.

## Theme / Goal

Build an app that becomes meaningfully better when both people *and* their AI
agents can use it together, using the emerging **WebMCP** open standard.
WebMCP lets a website expose structured "tools" that agents call directly
(instead of clumsily navigating the UI), so developers get to define exactly
how an agent interacts with their app — faster and more accurate task
completion than freeform UI automation.

This is a 10-day hackathon centered on agent-native web experiences.

## Submission Requirements

1. **Working live app** — reachable via ChatGPT's in-app browser or Chrome
   149+ with WebMCP enabled, hosted on ChatGPT Sites, Cloudflare, Vercel,
   Render, Netlify, or equivalent.
2. **Text description** covering:
   - Why WebMCP is a strong fit for the use case
   - How it improves the user experience
   - Novel human-agent collaboration it enables
   - The WebMCP implementation approach
3. **Public open-source code repo** (GitHub/GitLab/Bitbucket) containing:
   - Complete source code and assets
   - An open source license file
   - A working, properly configured WebMCP tool registration
4. **Demo video** — ≤3 minutes, public on YouTube, with clear audio
   explaining the build and WebMCP usage. No unauthorized third-party
   trademarks/copyrighted material.
5. **Project provenance** — must be newly created, or meaningfully extended
   with WebMCP, during the submission period. Pre-existing projects need
   documented evidence distinguishing prior work (timestamped commit
   history recommended).

## Judging Criteria

**Stage 1 (pass/fail):** Does the project fit the theme and actually apply
the required tech (WebMCP)?

**Stage 2 (four equally-weighted criteria):**
1. **WebMCP Leverage** — How thoroughly and skillfully is WebMCP used? Is
   there a genuine, working, non-trivial implementation?
2. **Execution** — Complete, coherent product experience beyond a
   proof-of-concept.
3. **Potential Impact** — Credible, specific case for solving a real problem
   for a real audience.
4. **Creativity & Ambition** — Novel concept, differentiated from existing
   solutions.

Ties on all criteria are resolved by judge vote.
